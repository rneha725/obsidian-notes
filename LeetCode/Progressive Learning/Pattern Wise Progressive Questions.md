## How to use this

1. Go topic by topic, in the order below.
2. Open the topic's `Questions.md`. Each one has 3 stages: Core, Twists, Interview-hard.
3. Problems you already solved in NeetCode 150 are listed at the top of each file, so you don't repeat them.
4. Move on when you can solve one Stage 3 problem in about 40 minutes without hints.

## Round formats to know (2025–2026)

- **Meta:** one onsite coding round can be AI-enabled: a single multi-part problem in a real codebase.
- **Stripe:** practical coding, a bug-squash round and an integration round. Not LeetCode.
- **Airbnb:** a code-review round replaced the second coding round. Expect one Hard per coding round.
- **GitLab:** review a merge request, then improve the code live. Not LeetCode.
- **Booking:** a Spring Boot take-home in some loops, plus pair programming on it.
